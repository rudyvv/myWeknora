# T15：[CodeWiki] 系统、模块及业务流程骨架与首批卡片覆盖

已发布：[Issue #23](https://github.com/rudyvv/myWeknora/issues/23)；父 Spec：[Issue #8](https://github.com/rudyvv/myWeknora/issues/8)。标签 ready-for-agent；未实施。

## What to build

代表仓库形成可查看的主题骨架和覆盖清单，先生成约 20–40 张重要技术卡片，再按模块扩展。

## Acceptance criteria

- [ ] 组件/入口清单驱动系统概览、模块职责和核心流程主题，不复制目录树或为全部方法生成页面。
- [ ] 骨架有有界独立检查，去重保持仓库身份；生成代码可作证据但不产生大量主动主题。
- [ ] 覆盖展示计划、就绪、草稿、失败/证据不足和待扩展，首批数量不是永久总上限。
- [ ] 业务流程卡片使用已验证静态链与配置证据，未知动态关系明确标注；可用证据时生成图而不替代引用。
- [ ] 骨架、卡片和整批 QA 都受累计上限；用户无须新增逐卡审批，原目录/链接体验继续可用。
