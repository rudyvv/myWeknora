# GitLab 源码范围步骤自动检查

日期：2026-10-08；工作树：`source-integration/WeKnora`；分支：`codex/gitlab-code-wiki-rag`。

## 用户目标和实现

源码接入与文档接入一样由“下一步”推进，不要求用户额外点击“预览固定提交”。检查能力继续保留。

- 源码模式点击“下一步”自动调用现有 source-preview API；检查通过才进入同步策略，失败停留在范围页面。检查期间显示中文进度并防止重复请求。
- 成功和失败均以文件数量及可操作问题说明呈现；提交编号、规则版本、原始诊断、搜索与分页文件清单位于默认折叠的详细信息中。成功摘要也显示在同步策略页。
- 此次初版曾要求源码目录必填；随后依据用户要求在 [全仓范围支持](codewiki-whole-repository-20261008.md) 中取消此限制。当前源码和文档均允许目录留空选择整个仓库，源码仍在下一步检查实际条件。
- 沿用现有草稿、凭证及版本失效机制，关闭、修改配置或凭证后，旧响应不能显示或推进步骤。不会通过预览修改已有数据源或触发同步。

本次没有修改后端同步、发布或源码 QA 规则。模型配置、解析服务和资源预算等不满足条件时仍会阻止接入。检查摘要中的无法处理数量是预览中 included/excluded 之外的文件数，最终解析和发布仍由真实同步决定。
