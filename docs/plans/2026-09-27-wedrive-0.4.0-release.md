# 微盘扫描协议 0.4.0：内部发布与验收

对应 [Issue #6](https://github.com/rudyvv/myWeknora/issues/6)、[Spec](2026-09-26-wedrive-scan-lifecycle-spec.md)。最低工具版本 0.4.0，当前内部候选包 0.4.2；服务端、页面和新包同批交付。当前内部包按项目负责人 2026-09-27 的决定不要求代码签名；设备请求签名、旧版本闸门和扫描尝试身份校验继续强制执行。

## 构建与部署

1. 在仓库中执行 `agents/wedrive-sync/build-windows.ps1 -AllowUnsigned -PublishUnsigned`。脚本核对项目和源码版本、嵌入 Windows 版本信息、检查 PyInstaller 退出码并运行 EXE `--version`，成功后才更新下载目录。签名发布改用 `-CertificateThumbprint` 和 `-TimestampServer`，签名或时间戳校验失败会阻止发布。只传 `-AllowUnsigned` 不更新下载目录。
2. 确认网页下载目录同时存在版本包和固定名称别名；二者 SHA256 应与 `dist/WeKnora-WeDrive-Tool.exe` 一致。`VITE_WEDRIVE_AGENT_DOWNLOAD_URL` 如有配置，必须同时更新其目标产物；默认入口带 `?v=0.4.2` 避开旧缓存。下载按钮保存为版本文件名。EXE 不提交 Git，应随部署复制或由构建流程生成。
3. 备份数据库，用项目的迁移入口执行全部待应用的 up 迁移。`AUTO_MIGRATE=true` 时新后端启动会执行；禁用时先单独调用 `database.RunMigrationsWithOptions`。PostgreSQL 目标 101，SQLite 目标 22。脏迁移状态先查失败原因，不自动 force，也不运行 down 后重试。
4. 用当前分支源码重新启动后端和前端。停止旧同步工具并双击 0.4.2 包；复用现有设备注册及浏览器 Profile，无需新建同步源。仅手动源不因启动、重连或刷新自动扫描。
5. 验证运行库迁移版本无 dirty、没有无身份/无租约的 `running` 源、微盘数据源没有内容入库 Cron。迁移 99/20 将旧无身份运行记录转为可重试状态；迁移 101/22 为现有有效尝试补进展基线，不删除历史完整清单。

## 回滚限制

应用迁移后，服务端最低回退目标必须仍包含 T2–T4 的协议闸门、尝试匹配和续租/超时处理。不得降级至接受无身份写入的服务端，不执行删除尝试身份列的 down 迁移，也不得重新分发 0.3.1。发生故障时先停同步工具，保留升级后的库及完整清单，修复后继续。若确需恢复迁移前备份，应在服务停止且全部设备无法连接的隔离环境中进行；重新开放扫描前再次升级并执行迁移，旧结果不能清算新领取。

## 自动验收

- 实际 Python `APIClient` → Ed25519 签名 HTTP → Go Handler → SQLite：仅手动源拒绝计划领取；252 条目录清单分两批上传并完整提交；重复开始和等价提交重试；新领取后旧尝试不能开始、上传、提交、续租或报告失败；0.3.1 的六类写入均拒绝升级，并且不能改变当前尝试。
- 公开 `WeDriveService` 与可控时钟：有进展扫描超过 30 分钟后提交、有效尝试跨服务对象重建保留、运行中调整频率、20 分钟无进展及 4 小时上限、迟到结果拒绝。同设备并发领取与续租/提交竞争在实际 PostgreSQL 临时 schema 验证。
- PostgreSQL 96–101 与 SQLite 17–22 升级场景包含历史无身份运行记录清理、完整清单保留、内容计划清除；SQLite 完整迁移入口另验证全新库与旧库升级。

跨语言验收命令（Python 已安装工具依赖）：

```powershell
$env:WEKNORA_WEDRIVE_TEST_PYTHON = (Resolve-Path agents/wedrive-sync/.venv/Scripts/python.exe).Path
go test ./internal/handler -run '^TestWeDrivePythonClientEndToEnd$' -count=1 -v
```

Windows Go/SQLite CGO 需要依照 `scripts/setup_sqlite_cgo.sh` 配置 include 路径。PostgreSQL 集成测试另需 `WEKNORA_WEDRIVE_TEST_POSTGRES_DSN`，只在临时 schema 中运行，不能用它替代实际应用库迁移。
