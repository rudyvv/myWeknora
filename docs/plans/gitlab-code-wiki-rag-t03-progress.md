## 已验证的首个切片

公开 HybridSearch 增加 `source_ids` 范围，以 GitLab 数据源身份区分仓库接入，不依赖路径或同名符号。范围传入关键词和向量检索，通过类型化 source chunk/file 关系在 SQL 截断前过滤；未知 source ID 返回空结果。未支持源码范围的检索引擎拒绝请求，不能忽略参数并扩大结果。

公开集成测试在同一 KB 创建两个独立源，接入相同路径与方法名，使用真实 Git、解析器和 PostgreSQL/ParadeDB。原实现先复现未知源仍返回命中的失败；修复后两路的 source 范围与独立文件身份通过，最终测试 10.950 秒。选定 HybridSearch/Composite 回归通过。测试不是本 ticket 全部验收，也没有测量大数据候选截断效果。
