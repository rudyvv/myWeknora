# ADR-0009：源码由 Git 管理，技术 Wiki 按完整来源校验读取范围

- 状态：Accepted（Q36、Q37）
- 日期：2026-09-28

源码采用稳定 Knowledge 身份接入现有工具，但普通文档编辑可修改 Text 块，重解析会先清资源；现有 Wiki 又允许任一来源命中文件/tag 就读取整页。直接沿用这两类行为会分别破坏固定提交证据和请求的内容范围，因此采用以下边界。

Git 管理的源文件原文与块只读。普通文档写入口拒绝正文编辑/回滚、块开关、普通重解析、直接删除及跨库移动/复制；标签和描述继续管理，重新加工走源码运行，移除文件走排除规则与完整快照发布，跨库接入建立独立同步源。技术 Wiki 正文保留既有编辑和修订能力；明确清除仓库知识仍按独立清除流程执行。

含源码贡献的页面只有全部正文来源都满足知识库权限和本次仓库/文件/tag 范围，且来源完整可验证时才整页返回；检查也覆盖摘要、命中片段、关联摘要、目录和历史读取。首期不自动裁剪混合段落，普通文档 Wiki 保持原行为。相较任一来源命中就放行，这降低窄范围 Wiki 命中率，但避免整页包含范围外内容，也省去段落裁剪和跨来源说明重组；用户可以扩大到模块/仓库范围，或用源码 RAG 读取所选文件。

该决定复用 Knowledge 的范围身份，但不能只隐藏 UI 按钮或过滤引用链接，必须覆盖服务端写入口与所有页面读取路径。依据及实施安排见 [整体方案](../plans/gitlab-code-wiki-rag-implementation-plan.md)。
