# ADR-0007：历史代码证据随现有 Wiki 修订与有效引用保留

- 状态：Accepted（Q25 按用户要求核查既有逻辑后决定，持久化与回收机制待设计）
- 日期：2026-09-28

WeKnora 原文档更新会替换旧块、索引及部分上传对象，Wiki 修订只保存页面正文等字段，并不保证旧来源可读取。技术卡片已要求固定提交追溯与应用内阅读，因此沿用原 Wiki 的有限修订保留规则，同时保留当前卡片、保留中的修订或运行任务所引用的不可变旧源码文件；引用释放后可清理，旧检索索引不因修订而长期保留。

现有 50/200 规则按页面版本窗口裁剪，页面删除释放全部修订；代码证据跟随实际保留中的正文，不另设按天归档策略。相较保留每次提交的完整仓库历史，此选择限制存储增长；相较直接复用原文档清理流程，它增加证据引用与安全回收管理，但可保证保留中的技术说明不会错误地读取新代码。Git 缓存仅用于同步，历史证据不依赖缓存永远保留或 GitLab 远端永远可达，首期仍只检索当前已发布源码快照。
