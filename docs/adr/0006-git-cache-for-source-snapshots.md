# ADR-0006：源码快照通过受控 Git 缓存获取，REST 管理项目元数据

- 状态：Accepted（获取方式已确认，缓存实现与生命周期待设计）
- 日期：2026-09-28

现有 GitLab 文档连接器使用 REST 逐文件获取内容，而代表源码仓库约有 3,844 个自有文本文件、125 万行，并需固定提交读取、完整清单对账及频繁增量更新。用户在 Q15 确认采用服务端 Git 缓存获取源码，REST 保留项目发现与权限验证等元数据职责。

缓存按需更新指定分支，在确定提交 SHA 下读取文件并计算差异，不执行目标仓库代码。相较全部沿用 REST 文件请求，这便于仓库级源码遍历与差异处理，但增加 Git 运行依赖、缓存空间和凭据使用管理；缓存隔离、历史证据保留、同源执行与清理机制须在完整实现方案中明确。
