# ADR-0005：首期源码加工采用静态分析，不要求目标项目可运行或可编译

- 状态：Accepted（能力范围已确认，解析器与执行边界待设计）
- 日期：2026-09-28

代表仓库包含 Java 8、Spring MVC、MyBatis、两个 Vue 2 前端与混合模板，并有较多生成代码及超大业务文件。为覆盖既有项目而不引入目标项目运行环境、完整依赖与构建成功的前置条件，首期通过静态分析提取源码结构与常见业务关联，不执行目标项目代码，也不要求目标项目编译成功。

关联范围包括 Controller、Service、Java Mapper 方法与 XML SQL，以及 Vue 组件和 API 请求；反射、动态分派等不能确定的关系必须标注为未确定，不能把候选关系写成已证实调用。相较完整编译语义与精确全仓调用图，这降低语言环境和依赖治理的复杂度，但首期不能承诺动态运行关系的完备性。生成说明仍必须关联已检查的源码证据。
