# ADR-0004：源码双索引发布与技术 WikiPage 生成分阶段完成

- 状态：Accepted（发布语义已确认，具体持久化与执行机制待设计）
- 日期：2026-09-28

代表仓库拥有约 125 万行自有文本内容，源码检索与技术 WikiPage 生成的耗时和失败模式不同。为避免 Wiki 模型调用失败阻止已经加工完成的源码检索，用户在设计访谈 Q9 确认选择源码先可用、Wiki 独立重试。

一个代码同步源的新源码快照在切块、关键词索引和向量索引全部完成后，作为一组发布供检索使用；只拉取到提交或把加工任务入队不算发布成功。技术 WikiPage 独立追踪所依据的源码提交与更新状态，生成失败不回退已发布源码；旧卡片保留提交标记，过期卡片默认不参与针对当前源码的 RAG。

此决定允许“源码已更新，Wiki 待更新”的可见状态，以阶段状态取代单一同步成功标志。相较所有阶段完成后再统一发布，这提高源码可用性，但要求检索明确区分源码版本与卡片证据版本，并防止无标记地混合不同版本。同源串行与提交合并原则见设计访谈 Q24，历史代码证据保留见 ADR-0007；执行租约、证据复核及清理机制仍待后续设计。
